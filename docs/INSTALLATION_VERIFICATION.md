# Проверка установки Prism

Дата: 27 октября 2026 года, Europe/Moscow.

## Выполнено

Проверка проводилась в двух новых каталогах на Windows. В исходные копии не переносились `app/data`, локальный конфиг, junction, модели, Python, node_modules и пакеты действующей AI-среды. В PATH установщика оставались Git и системные каталоги Windows; использовался пустой тестовый профиль. Git, драйвер NVIDIA и VC++ Runtime уже были установлены в самой Windows.

Новые диффузии после первого прогона не запускались. Для будущей проверки отправки задания достаточно четырёх шагов на низком разрешении; повторение установки само по себе не требует генерации.

## Регрессионные проверки

- 147 JS-тестов в 60 файлах прошли. Каждый файл запускался отдельным скрытым Node-процессом с `--test-isolation=none`, чтобы сам test runner не создавал дополнительные консоли.
- Все 15 Python-сценариев прошли в новом окружении: 52 unittest-проверки и четыре скрипта с assertions. Тензорный тест шума использует CPU и не выполняет диффузию.
- TDD установки покрывает план без изменений файлов, защиту чужого окружения и существующего backend, повторный запуск, смену профиля, возобновление загрузки, SHA256, сохранение конфига и порта, общую блокировку с лончером.
- Проверки лончера покрывают неполную установку, Windows venv redirector, завершение дочернего backend, повторное подключение, остановку, защиту занятых очередей, проверку Git и обновление временного fixture-репозитория с резервной копией.
- Проверки интерфейса первого запуска покрывают отсутствие модели, повторную проверку, подготовку примера и потерю связи с backend.

В изоляции были обнаружены и исправлены зависимость отдельных тестов от неявного PYTHONPATH и запуск HTTP-теста на фиксированном порту. Теперь HTTP-тест требует явный `PRISM_TEST_URL`, а тензорный тест требует `PRISM_TEST_COMFY_ROOT`.

Для повторения Python-проверок в отдельной установленной тестовой копии:

```powershell
$repo = (Get-Location).Path
$env:PYTHONPYCACHEPREFIX = "$repo/.cache/pycache"
$env:PIP_CACHE_DIR = "$repo/.cache/pip"
$env:TORCHINDUCTOR_CACHE_DIR = "$repo/.cache/torchinductor"
$env:PRISM_TEST_COMFY_ROOT = "$repo/.runtime/ComfyUI"
$env:PRISM_TEST_URL = 'http://127.0.0.1:8197'
$python = "$repo/.runtime/venv/Scripts/python.exe"
Get-ChildItem app/tests/test_*.py | ForEach-Object { & $python $_.FullName; if ($LASTEXITCODE) { throw $_.Name } }
```

Для HTTP-теста отдельный backend на выбранном адресе должен уже работать. Тест временно изменяет его пресеты и удаляет свою запись после проверки. Не направляйте его на рабочую среду. Остальные тесты создают свои временные данные. Для JS-тестов нужны Node.js 24+ и dev-зависимости из `app/package-lock.json`; npm-кэш задаётся через `npm_config_cache` в проектной `.cache`.

## Границы проверки

Это чистые каталоги и независимые Python-окружения на существующей Windows, а не новая VM или другой компьютер. Установка системных Git, VC++ и драйвера с нуля, перезагрузка Windows, другие видеокарты и объёмы памяти не проверялись. NVIDIA-профиль проверен до работоспособного backend и интерфейса; нового NVIDIA-прогона диффузии не было.

Дополнительные Qwen/Anima, FaceDetailer, ReActor и upscale-модели начальным установщиком не устанавливаются и здесь повторно не проверялись. Обновление проверено на fixture-репозитории; установка будущего релиза ComfyUI требует проверки совместимости его зависимостей. Сборок Python из исходников и установки sdist нет: используются готовые wheels.

Журналы, JSON-результаты и скриншоты этой проверки сохранены локально в `.cache/onboarding` и не включаются в Git. Рабочие Python, модели и конфигурация существующей AI-среды не переустанавливались.
