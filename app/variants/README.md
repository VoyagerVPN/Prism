# Варианты управления персонажем

Три независимых интерактивных прототипа для сравнения работы с шаблоном персонажа и его текущим состоянием при подготовке генерации.

Запуск из корня `D:/AI/Prism`:

```powershell
node app/variants/server.mjs
```

Общая страница: http://127.0.0.1:8190/

- http://127.0.0.1:8190/variant1/
- http://127.0.0.1:8190/variant2/
- http://127.0.0.1:8190/variant3/

Основной Prism должен работать на порту 8188. Предпросмотр читает только персонажей, библиотеку LoRA и локальные превью. Запись в основную базу, запуск генерации и прочие запросы backend через этот сервер недоступны. Локальные изменения каждого варианта изолированы в его браузерном хранилище.

Для сравнения попробуйте одинаковый сценарий: выбрать Isabella, увидеть теги внешности и комплекта, изменить несколько тегов для текущего изображения, затем открыть карточку и разобраться с тегами автора. Проверьте, понятно ли, какие изменения относятся к текущему изображению, а какие — к заготовке персонажа. Интерфейсы предлагают собственные способы решить эту задачу.

Проверка сервера:

```powershell
$env:npm_config_cache='D:\AI\Prism\.cache\npm'
node --test app/variants/server.test.mjs
```
